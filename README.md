# 📊 Supermarket Sales Analysis Dashboard – Power BI Project

## ✅ Project Overview
This is a beginner-friendly **Power BI** project where I analyzed supermarket sales data to uncover trends, category performance, and regional insights. The project covers key steps such as data cleaning, modeling, creating DAX measures, and building interactive visualizations. It’s designed to demonstrate practical Power BI skills for aspiring data analysts.

---

## 📂 Dataset
The dataset used in this project contains supermarket sales transaction data, including:
- Transaction dates
- Product categories
- Sales amount and quantity sold
- Region and customer demographics

The dataset file is available in the [`data/`](data/) folder as `supermarket_sales.csv`. It’s sourced from publicly available data and structured for learning purposes.

---

## 📈 Features & Insights
✔ Total sales, quantity, and average sales metrics  
✔ Year-to-Date (YTD) and Month-over-Month (MoM) sales trends  
✔ Performance analysis by product category and region  
✔ Interactive charts, slicers, and filters for data exploration  
✔ User-friendly layout with clear labels, tooltips, and navigation  

**Key insights:**
- Identify top-selling products and regions  
- Analyze sales patterns over time  
- Compare performance across categories  

---

## 🛠 Tools & Techniques Used
- **Power BI Desktop** for data visualization and reporting  
- **Power Query Editor** for data cleaning and transformation  
- **DAX** for creating calculated measures like Total Sales, YTD, MoM growth  
- **Date Table** for time intelligence analysis  
- Interactive visuals including line charts, bar charts, pie charts, and cards
